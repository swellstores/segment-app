# Segment

Connect your Swell store to Segment to send store events automatically, and from there to Google Analytics, Intercom, HubSpot and hundreds of other Segment destinations.

- **Choose your events:** pick which store events to send, grouped by accounts, carts, categories, coupons, invoices, orders, pages, payments, products, promotions, shipments and subscriptions.
- **Readable event names:** events arrive as Segment `track` calls with clear names like Order Paid, Cart Abandoned or Account Created.
- **Full event data:** each event carries the complete record (order, cart, customer and so on) as its properties.
- **No duplicates:** each event keeps its Swell event ID, so Segment ignores repeat deliveries if Swell retries one.
- **Same format as Swell's built-in integration:** a drop-in replacement for the built-in Segment integration, so your Segment data and destinations keep working.
- **Simple setup:** paste your Segment write key, choose your region (US or EU) and select events. Pause any time with the Enabled toggle.
